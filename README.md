# Student Performance Prediction

Проект по анализу табличных данных о студентах и построению модели машинного обучения для предсказания итоговой успеваемости.

Цель проекта - постепенно построить понятный и воспроизводимый ML-пайплайн: от загрузки данных и первичного анализа до baseline-модели, модели градиентного бустинга, оценки качества и анализа ошибок.

## Структура проекта

```text
student-performance-model/
  data/
    raw/                 # исходные CSV-файлы, хранятся локально
    processed/           # обработанные данные
  notebooks/             # исследовательские ноутбуки
  src/                   # основной Python-код проекта
    data_loader.py       # функция загрузки CSV-данных
  reports/
    figures/             # графики и визуализации

  README.md              # описание проекта
  requirements.txt       # зависимости Python
  .gitignore             # файлы и папки, исключенные из Git
  .gitattributes         # настройки обработки текстовых файлов в Git
```

## Данные

В проекте используются два CSV-файла:

- `student_data.csv` - базовый датасет.
- `student_data_500k.csv` - расширенный датасет.

Файлы должны находиться локально в `data/raw`.

CSV-файлы не добавляются в Git, чтобы не хранить большие данные в репозитории. Структура папки `data/raw` сохраняется через файл `.gitkeep`.

Текущий учебный анализ начинается с маленького датасета `student_data.csv`, потому что на нем проще отлаживать код, проверять идеи и понимать каждый шаг. Отдельно планируется повторить анализ и обучение на `student_data_500k.csv`, чтобы сравнить, влияет ли размер датасета на качество и скорость обучения модели.

На следующих этапах нужно:

- изучить размерность данных;
- посмотреть названия и типы столбцов;
- определить целевую переменную;
- проверить пропуски;
- проверить категориальные и числовые признаки;
- сравнить результаты на маленьком и расширенном датасетах.

## Метрики качества

Планируемые метрики:

### RMSE

```text
RMSE = sqrt(mean((y_true - y_pred)^2))
```

RMSE показывает среднюю ошибку модели в единицах целевой переменной и сильнее штрафует большие ошибки.

### MAE

```text
MAE = mean(abs(y_true - y_pred))
```

MAE показывает среднюю абсолютную ошибку модели.

### R2

```text
R2 = 1 - sum((y_true - y_pred)^2) / sum((y_true - mean(y_true))^2)
```

R2 показывает, какую долю разброса целевой переменной объясняет модель.

Реальные значения метрик будут добавлены только после запуска кода обучения.
