# Student Performance Prediction

Проект по анализу табличных данных о студентах и построению модели машинного обучения для предсказания итоговой успеваемости.

Цель проекта - постепенно построить понятный и воспроизводимый ML-пайплайн: от загрузки данных и первичного анализа до baseline-модели, модели градиентного бустинга, оценки качества и анализа ошибок.

## Структура проекта

```text
student-performance-model/
  data/
    raw/                 # исходные CSV-файлы, хранятся локально
    processed/           # обработанные данные
  notebooks/             # исследовательские ноутбуки
  src/                   # основной Python-код проекта
    data_loader.py       # функция загрузки CSV-данных
  reports/
    figures/             # графики и визуализации
    tables/              # таблицы с метриками и результатами

  .gitignore             # файлы и папки, исключенные из Git
  .gitattributes         # настройки обработки текстовых файлов в Git
```

## Модели

Уже проверены:

- `DummyRegressor(strategy="mean")` - baseline-модель, которая предсказывает среднее значение `G3`.
- `LinearRegression` - простая линейная модель для первичного сравнения с baseline.
- `HistGradientBoostingRegressor` - основная нелинейная модель для большого табличного датасета.
- отдельное сравнение сценариев с `G1`/`G2` и без `G1`/`G2`;
- отдельное сравнение обучения на маленьком и расширенном датасетах.

Основные параметры бустинга:

```text
learning_rate=0.005
max_iter=50000
max_leaf_nodes=31
min_samples_leaf=50
l2_regularization=1.0
early_stopping=True
validation_fraction=0.1
n_iter_no_change=30
random_state=42
```

`max_iter=50000` используется как верхний предел. Благодаря early stopping модель с `G1`/`G2` остановилась на 18 665 итерациях, а модель без `G1`/`G2` - на 44 025 итерациях.

## Метрики качества

Планируемые метрики:

### RMSE

```text
RMSE = sqrt(mean((y_true - y_pred)^2))
```

RMSE показывает среднюю ошибку модели в единицах целевой переменной и сильнее штрафует большие ошибки.

### MAE

```text
MAE = mean(abs(y_true - y_pred))
```

MAE показывает среднюю абсолютную ошибку модели.

### R2

```text
R2 = 1 - sum((y_true - y_pred)^2) / sum((y_true - mean(y_true))^2)
```

R2 показывает, какую долю разброса целевой переменной объясняет модель.

Реальные значения метрик добавляются только после запуска кода.
