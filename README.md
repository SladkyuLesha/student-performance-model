# Student Performance Prediction

Проект по анализу табличных данных о студентах и построению модели машинного обучения для предсказания итоговой оценки `G3`.

Главная цель проекта - постепенно собрать понятный и воспроизводимый ML-пайплайн: загрузка данных, первичный анализ, preprocessing, честное разбиение train/test, baseline-модель, градиентный бустинг, оценка качества, анализ ошибок и сохранение результатов.

## Данные

В проекте используются два CSV-файла:

- `student_data.csv` - базовый датасет на 395 строк.
- `student_data_500k.csv` - расширенный датасет на 500000 строк.

Источник базового датасета: [Student Performance Data на Kaggle](https://www.kaggle.com/datasets/devansodariya/student-performance-data).

CSV-файлы должны лежать локально в `data/raw`. Они не добавляются в Git, потому что данные могут быть большими и не должны храниться в репозитории.

Расширенный датасет содержит технический столбец `record_id`. Он исключается из признаков, потому что является идентификатором записи, а не характеристикой студента.

## Целевая Переменная

Целевая переменная:

```text
G3
```

`G3` - итоговая оценка студента. Задача проекта формулируется как регрессия: модель должна предсказывать числовое значение итоговой успеваемости.

В проекте сравниваются два сценария:

- с `G1` и `G2` - модель использует промежуточные оценки;
- без `G1` и `G2` - модель прогнозирует `G3` только по остальным признакам.

Такое сравнение нужно, потому что `G1` и `G2` очень сильно связаны с `G3`, но в реальной задаче они могут быть недоступны заранее.

## Текущий Pipeline В `src`

### Загрузка Данных

Файл:

```text

```

Функция:

```python
load_data(file_path)
```

Она принимает путь к CSV-файлу, проверяет, существует ли файл, и возвращает `pandas.DataFrame`.

### Preprocessing

Файл:

```text
src/preprocessing.py
```

Сейчас preprocessing делает три вещи:

1. Создает копию исходного dataframe.
2. Удаляет `record_id`, если такой столбец есть.
3. Кодирует категориальные признаки через `pd.get_dummies(..., drop_first=True, dtype=int)`.

Также подготовлены два набора признаков:

- `X_with_grades` - все признаки, кроме `G3`;
- `X_without_grades` - все признаки, кроме `G1`, `G2` и `G3`;
- `y` - целевая переменная `G3`.

### Честное Разбиение

Файл:

```text
src/splitting.py
```

Функция:

```python
honest_split_data(X, y, test_size=0.2, random_state=42)
```

Она использует `GroupShuffleSplit`, чтобы одинаковые строки признаков не попадали одновременно в train и test.

Группы строятся так:

```python
groups = pd.util.hash_pandas_object(X, index=False)
```

Это создает одинаковый числовой отпечаток для одинаковых строк признаков. После этого `GroupShuffleSplit` держит одинаковые группы вместе: они попадают либо в train, либо в test.

## Модели

### DummyRegressor

Baseline-модель:

```python
DummyRegressor(strategy="mean")
```

Она всегда предсказывает среднее значение `G3`. Нужна как точка отсчета: полезная модель должна быть лучше простого среднего.

### LinearRegression

Простая линейная модель для первичного сравнения. Она помогает понять, насколько хорошо итоговую оценку можно объяснить линейными зависимостями.

### HistGradientBoostingRegressor

Основная модель проекта для табличных данных. Это градиентный бустинг из scikit-learn, который умеет находить нелинейные зависимости.

Проверенные параметры в notebook:

```text
learning_rate=0.005
max_iter=50000
max_leaf_nodes=31
min_samples_leaf=50
l2_regularization=1.0
early_stopping=True
validation_fraction=0.1
n_iter_no_change=30
random_state=42
```

Перед переносом в `src` также использовался более быстрый запуск:

```text
max_iter=10000
early_stopping=True

```

## Метрики

### MAE

```text
MAE = mean(abs(y_true - y_pred))
```

Средняя абсолютная ошибка. Показывает, на сколько баллов в среднем ошибается модель.

### MSE

```text
MSE = mean((y_true - y_pred)^2)
```

Средняя квадратичная ошибка. Сильнее штрафует большие ошибки.

### RMSE

```text
RMSE = sqrt(MSE)
```

Корень из MSE. Измеряется в тех же единицах, что и `G3`.

### R2

```text
R2 = 1 - sum((y_true - y_pred)^2) / sum((y_true - mean(y_true))^2)
```

Показывает, какую долю разброса целевой переменной объясняет модель. Например, `R2 = 0.90` означает, что модель объясняет около 90% вариативности `G3` на выбранной проверочной выборке.

## Проверка Надежности Split

На расширенном датасете были найдены повторы:

| Проверка | Результат |
| --- | ---: |
| Полные дубликаты без `record_id` | 190064 |
| Доля полных дубликатов без `record_id` | 38.0128% |
| Дубликаты по признакам без `G3` | 274245 |
| Доля дубликатов по признакам без `G3` | 54.8490% |
| Test-строки, признаки которых уже были в train при random split | 63203 |
| Доля таких test-строк | 63.2030% |

Обычный random split оказался слишком оптимистичным: одинаковые строки признаков могли попадать одновременно в train и test.

Для более честной оценки добавлен `GroupShuffleSplit`:

| Split | Пересечения train/test | Доля пересечений | Train | Test |
| --- | ---: | ---: | ---: | ---: |
| По признакам с `G1/G2` | 0 | 0.0000% | 400013 | 99987 |
| Strict split без `G1/G2/G3` | 0 | 0.0000% | 400751 | 99249 |

`Strict GroupShuffleSplit` - это не отдельный класс scikit-learn, а наше название для более строгого варианта: группы строятся по признакам без `G1`, `G2` и `G3`.
