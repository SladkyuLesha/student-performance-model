# Student Performance Prediction

Проект по анализу табличных данных о студентах и построению модели машинного обучения для предсказания итоговой успеваемости.

Цель проекта - постепенно построить понятный и воспроизводимый ML-пайплайн: от загрузки данных и первичного анализа до baseline-модели, модели градиентного бустинга, оценки качества и анализа ошибок.

## Метрики качества

Планируемые метрики:

### RMSE

```text
RMSE = sqrt(mean((y_true - y_pred)^2))
```

RMSE показывает среднюю ошибку модели в единицах целевой переменной и сильнее штрафует большие ошибки.

### MAE

```text
MAE = mean(abs(y_true - y_pred))
```

MAE показывает среднюю абсолютную ошибку модели.

### R2

```text
R2 = 1 - sum((y_true - y_pred)^2) / sum((y_true - mean(y_true))^2)
```

R2 показывает, какую долю разброса целевой переменной объясняет модель.

Реальные значения метрик будут добавлены только после запуска кода обучения.
