# Паспорт моделей прогнозирования G3

## Назначение и данные

Учебный прогноз итоговой оценки G3 в диапазоне 0–20 по набору Student Performance. Ранний сценарий использует признаки без G1 и G2; поздний дополнительно использует G1 и G2. Это регрессия, а не классификация. Модели не предназначены для принятия автоматических решений о конкретном студенте.

Исходная часть содержит 237 записей. По фиксированному разбиению train — 151, validation — 38, test — 48. Сохранённые модели обучены повторно на 189 строках train + validation. Данные ранее исследовались, поэтому test не полностью независим от всей исследовательской работы. Порции составлены случайным разбиением исходного набора, а не получены в будущие периоды.

Обе модели сохранены как sklearn Pipeline: подготовка признаков, заполнение пропусков, масштабирование числовых и кодирование категориальных признаков, затем регрессор. Неизвестные категории игнорируются кодировщиком, но фиксируются проверкой входных данных. Подробности конфигурации и версии библиотек находятся в соответствующих JSON рядом с моделями.

## Ранняя модель

- Файл: `models/early_model.joblib`; Lasso, `alpha=1.0`, без G1/G2.
- Test: MAE 3,721; RMSE 4,986; R² 0,057; 48 строк. Медианный baseline: MAE 3,750.
- Заранее заданные условия: MAE не более 3,0 и улучшение над baseline не менее 0,1 балла. Оба условия на test не выполнены.
- Предварительное решение: **вернуть на доработку**; не применять для индивидуальных решений.

## Поздняя модель

- Файл: `models/late_model.joblib`; Random Forest из 100 деревьев, с G1/G2.
- Test: MAE 1,425; RMSE 2,324; R² 0,795; 48 строк. Медианный baseline: MAE 3,750.
- Заранее заданные условия: MAE не более 2,0 и улучшение над baseline не менее 0,3 балла. Оба численных условия на test выполнены.
- Предварительное решение: **исследовательское использование с ограничениями**, не как единственное основание решений о студенте. Крупные индивидуальные ошибки возможны, в частности для фактических нулевых оценок; значения G1/G2 и других признаков должны быть доступны на момент прогноза.

## Сравнение и ограничения

Для позднего сценария бустинг выбран по прежней CV и повторно обучается в notebook; отдельного файла модели пока нет. Его MAE test — 1,586. Это сравнение основано на малом наборе и не является доказательством превосходства модели за его пределами.

На test перестановочная важность G2 для позднего леса наиболее высокая. Важность не доказывает причинную связь. Нужно отдельно проверить доступность итогового количества пропусков и иных признаков на момент прогноза: иначе возможна утечка информации из будущего. Шкала и значение G3=0 должны быть проверены по документации источника перед содержательными выводами.

Границы применимости на других школах, годах и популяциях пока не подтверждены. Диапазоны значений и неизвестные категории новых данных следует проверять до прогноза. Условия автоматического переобучения и мониторинга пока не реализованы.

Дополнительные эксперименты устойчивости и перерасчёт PSI для дискретных признаков добавлены после просмотра test. Их результаты являются исследовательскими и будут рассмотрены после повторного запуска notebook. Численные критерии приёмки задним числом не меняются.
